apaf.security — Security Plugin

Overview

The apaf.security plugin is the core authentication and authorization engine of APAF. It verifies every incoming HTTP request, resolves the caller's identity from multiple credential types, and enforces role-based access control (RBAC) on all protected endpoints. The service is available as apaf-security:
let security = plugin.getService('apaf-security');

Service Name

'apaf-security'

Authentication Mechanisms

The security plugin resolves the caller identity from the following sources, checked in order:
  • HTTP session — an active browser session established via the login page
  • Basic auth — Authorization: Basic <base64(login:password)>
  • Bearer token — Authorization: Bearer <token> (APAF token)
  • API key header — X-Api-Key: <base64(login:apiKey)>
  • Query parameter — ?apiKey=<base64(login:apiKey)>

Methods

checkAuthentication(req, res, role, then)

Verifies that the request is authenticated and that the resolved user holds the given role. If authorization fails, the response is terminated with HTTP 401. Otherwise then(user) is called with the resolved User record. Pass an empty string for role to require authentication only (no specific role).

getLoginFromRequest(req)

Extracts the login name from the request using all supported authentication mechanisms. Returns null if no valid credentials are found.

getUserRecord(login, callback)

Returns the full User record for the given login name.

updateRecord(login, data, callback)

Updates the User record identified by login with the provided data.

REST API

MethodPathRoleDescription
GET/apaf-security/getApiKey(authenticated)Generate and return a new API key for the currently authenticated user

Telemetry

The plugin contributes a telemetry dimension:
  • secure.api.call — counts every authenticated HTTP request per 30-second interval

Notes

  • All APAF REST handlers call checkAuthentication() — the security plugin is therefore a hard dependency for every other APAF plugin.
  • Roles are defined as records in the apaf_roles CouchDB database and managed via the apaf.admin plugin.
  • The built-in role administrator grants access to all protected administration endpoints.
