Environment variables — NPA & APAF

Overview

This page lists the environment variables declared in the manifest.json files of the Node-Plugin-Architecture (NPA) and APAF plugins, ordered by plugin. The variables declared by the apaf-ext plugins are listed in the Environment variables (APAF extensions) page.

Declaration syntax

Two syntaxes are used in the manifests:
  • "$VARIABLE_NAME,default" — a configuration value read at startup. The text after the comma is the default value used when the variable is not defined in the environment. When no comma is present, the default value is an empty string.
  • "environment": { ... } block of an npa.couchdb.adapter.datasource extension — maps the datasource properties hostname, port, username and password to environment variable names. When a variable is not defined, the literal value declared in the datasource (hostname, port) is used. The credentials are used only if both the user name and the password variables are defined.

Variables shared with the launcher (app.js)

The launcher app.js also sets some of these variables (LOG_DIR, LOG_LEVEL, APPLICATION_NAME, PORT) from the command-line arguments (--logs, --level, --name, --port) before the plugins are loaded. When app.js sets a variable, its value takes precedence over the default value declared in the plugin manifest.
