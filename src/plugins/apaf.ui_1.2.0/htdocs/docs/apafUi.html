apaf.ui — Advanced UI Plugin

Overview

The apaf.ui plugin contributes APAF-specific UI components to the NPA UI framework (npa.ui.tools.core). Components live in the apafUi namespace and are referenced in a component JSON configuration as apafUi.<Name>.

Since version 1.1.0 the plugin also serves the Chart.js library (v4.4.7, UMD build) from /apaf-ui/lib/chart.umd.js, and provides the LineChart component.

Version 1.2.0 adds a family of statistical chart components sharing the same conventions as LineChart: BarChart, PieChart (camembert), DoughnutChart, RadarChart (star), PolarAreaChart and ScatterChart.

LineChart component

The developer only declares a placeholder <div> and a JSON configuration. The component creates and sizes the <canvas>, loads Chart.js on demand (only if the Chart global is not already defined), builds, updates and destroys the chart instance. The chart is responsive and fits the width of its parent <div>.

Usage

<div id="salesChartDiv" class="npaUi" data-config="/my-plugin/json/salesChart.json"></div>
{
  "id": "salesChart",
  "type": "apafUi.LineChart",
  "version": "1.0.0",
  "configuration": {
    "title": "@my.plugin.sales.title",
    "height": 300,
    "labelField": "month",
    "series": [
      {"field": "revenue","label": "@my.plugin.sales.revenue"},
      {"field": "cost","label": "@my.plugin.sales.cost","color": "#e5484d","fill": true}
    ],
    "yAxisLabel": "EUR",
    "datasource": {
      "type": "local",
      "uri": "/my-plugin-api/sales",
      "adapter": "@.data"
    }
  }
}

Configuration

PropertyTypeDescription
titlestringOptional chart title; supports i18n references (@key)
heightintegerChart height in pixels (default 300)
labelFieldstringRow attribute used for the X axis labels
seriesarrayOne entry per curve: field (row attribute holding the Y value), optional label, color and fill
xAxisLabel / yAxisLabelstringOptional axis titles; support i18n references
legendbooleanDisplay the legend (default true)
smoothbooleanSmooth the curves (default true)
beginAtZerobooleanForce the Y axis to start at 0 (default false)
datasourceobjectData source, same conventions as the Datatable component (see below)
selectionListener / selectionProviderboolean / stringWhen set, the chart is refilled when the given component fires a select event
selectionAdapterstringExpression returning the rows array from the selected item (@ represents the item); the item itself is used if omitted

Datasource

TypeDescription
local (default)REST call on uri (method, payload optional). The rows are read from the data attribute of the response, or from the result of the adapter expression (@ represents the response)
managedRows returned by query(payload) of the DataManager component identified by manager
manual (or no datasource)Rows provided by the application through setData(rows)

Methods

MethodDescription
setData(rows)Replace the displayed rows and update the chart
refresh()Reload the data from the datasource
onItemSelected(item)Selection listener callback

Events

Clicking a point fires the select event with {"source": <component id>, "item": <the row>}, so other components can listen to it with selectionProvider.

Statistical charts (since 1.2.0)

The six components below are implemented in /apaf-ui/js/charts.js on top of a common base class, and share the behaviour of LineChart: the developer declares a placeholder <div> and a JSON configuration; the component creates the canvas, loads Chart.js on demand, is responsive, shows a localized « no data » message when empty, and supports the same datasource, selectionListener / selectionProvider / selectionAdapter settings, the setData(rows) / refresh() / onItemSelected(item) methods and the select event (fired when an element of the chart is clicked, carrying the underlying row).

Common configuration

PropertyTypeDescription
titlestringOptional chart title; supports i18n references (@key)
heightintegerChart height in pixels (default 300)
legendbooleanDisplay the legend (default true)
legendPositionstringtop (default), bottom, left or right
datasourceobjectSame as LineChart (local, managed or manual)
selectionListener / selectionProvider / selectionAdapterboolean / string / stringSame as LineChart

BarChart and RadarChart

One value per series for each row; the row attribute labelField provides the category label.

{
  "id": "regionBars",
  "type": "apafUi.BarChart",
  "version": "1.0.0",
  "configuration": {
    "title": "@my.plugin.sales.title",
    "labelField": "region",
    "series": [
      {"field": "q1","label": "Q1"},
      {"field": "q2","label": "Q2","color": "#e5484d"}
    ],
    "horizontal": false,
    "stacked": false,
    "yAxisLabel": "Units"
  }
}
PropertyApplies toDescription
labelFieldbothRow attribute holding the category label
seriesbothArray of {"field","label","color"}; RadarChart series also accept "fill" (default true)
horizontalBarChartDraw horizontal bars (default false)
stackedBarChartStack the series instead of grouping them (default false)
xAxisLabel / yAxisLabelBarChartOptional axis titles; support i18n references
beginAtZerobothForce the value axis to start at 0 (default true)

PieChart, DoughnutChart and PolarAreaChart

One value per row; each row is a slice.

{
  "id": "shareChart",
  "type": "apafUi.PieChart",
  "version": "1.0.0",
  "configuration": {
    "title": "Market share",
    "labelField": "browser",
    "valueField": "share",
    "valueLabel": "Share (%)",
    "showPercentage": true,
    "legendPosition": "right"
  }
}
PropertyDescription
labelFieldRow attribute holding the slice label
valueFieldRow attribute holding the numeric value
valueLabelOptional dataset label shown in the tooltip; defaults to valueField
colorsOptional array of CSS colors used cyclically for the slices (default palette otherwise)
showPercentageAppend the percentage of the total to the tooltip (default false)
cutoutDoughnutChart only: size of the hole, in pixels or percentage string (default "50%")

ScatterChart

Each series draws one point per row, positioned with two numeric row attributes.

{
  "id": "correlation",
  "type": "apafUi.ScatterChart",
  "version": "1.0.0",
  "configuration": {
    "series": [
      {"xField": "height","yField": "weight","label": "Group A","radius": 5}
    ],
    "xAxisLabel": "Height (cm)",
    "yAxisLabel": "Weight (kg)"
  }
}
PropertyDescription
seriesArray of {"xField","yField","label","color","radius"}
xAxisLabel / yAxisLabelOptional axis titles; support i18n references
beginAtZeroForce both axes to start at 0 (default false)

Example

The Charts Demo user application (APAF user applications) shows each component in its own tab of a TabPane.

Chart.js library

The library is served as a static resource of this plugin. Any other page can use it directly:

<script src="/apaf-ui/lib/chart.umd.js"></script>
