apaf.telemetry — Telemetry Plugin

Overview

The apaf.telemetry plugin exposes the NPA in-memory telemetry store as a REST API, making it consumable by APAF UI dashboards and external monitoring tools. It does not collect metrics itself — it delegates entirely to the underlying npa.telemetry service, which aggregates time-series data pushed by other plugins.

REST API

MethodPathRoleDescription
GET/apaf-telemetry/listtelemetryConsumerGet the list of all declared telemetry dimensions (without data)
GET/apaf-telemetry/dimension/:dimensionNametelemetryConsumerRetrieve all data points for the named dimension

Declaring a Custom Dimension

Any plugin can contribute a telemetry dimension via the npa.telemetry.dimension.provider extension point. See the npa.telemetry documentation for the full schema.

Notes

  • The telemetryConsumer role is required to read telemetry data via the REST API. It is automatically seeded at startup.
  • All telemetry data is in-memory — data points are lost on server restart.
  • The GET /apaf-telemetry/list endpoint returns only dimension metadata (name, label, type, unit) without the data array, making it efficient for discovery.
