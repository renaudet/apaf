apaf.datatype — Datatype Persistence Plugin

Overview

The apaf.datatype plugin is the persistence backbone of APAF. It manages the registration and lifecycle of datatypes — named schemas that describe CouchDB-backed data collections. Every APAF plugin that needs to store records uses this plugin to declare its datatype and then delegates all CRUD operations to it.

Declaring a Datatype

A plugin registers its datatype by contributing to the apaf.datatype.base.datatype extension point in its manifest.json:
 1. {
 2.   "point": "apaf.datatype.base.datatype",
 3.   "id": "my.plugin.datatype",
 4.   "datatype": {
 5.     "name": "myRecord",
 6.     "persistent": true,
 7.     "database": "apaf_my_records",
 8.     "primaryKey": "name"
 9.   }
10. }
If persistent is true, the plugin creates the CouchDB database on startup if it does not already exist.

Programmatic API

The plugin is accessed through its plugin instance (not a named service). Other APAF plugins resolve it via the NPA core:
let datatypePlugin = plugin.getService('core').getPlugin('apaf.datatype');

query(datatypeId, selector, callback)

Executes a CouchDB Mango query on the named datatype's database. selector is a plain Mango selector object (e.g. {"active": {"$eq": true}}). The callback receives (err, records[]).

findByPrimaryKey(datatypeId, data, callback)

Finds a single record matching the primaryKey value from data. Returns null if not found.

createRecord(datatypeId, data, callback)

Creates a new record. Automatically adds id, created, and createdBy fields if not already present.

updateRecord(datatypeId, data, callback)

Updates an existing record. Merges data onto the existing CouchDB document (fields absent from data are preserved). Requires id and _rev.

deleteRecord(datatypeId, data, callback)

Deletes the record identified by data.id.

Extension Points

  • apaf.datatype.base.datatype — declare a datatype that this plugin will manage. Consumed by all APAF feature plugins.
  • apaf.datatype.object.initializer — seed initial records into a datatype database at startup (used to create default roles such as administrator, developer, operator).
