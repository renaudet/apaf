apaf.admin - User, Group & Role Management

This plugin provides REST APIs and UI views for managing APAF Users, Groups, Security Roles and User Profiles.

Server Stats page

The Diagrams section of the Server Stats page (/apaf-admin-ui/html/stats.html) displays one line chart per telemetry counter. Since version 1.2.0 the charts are apafUi.LineChart components (Chart.js) provided by the apaf.ui plugin (version 1.1.0 or later).
