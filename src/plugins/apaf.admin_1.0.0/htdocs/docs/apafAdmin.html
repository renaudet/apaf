apaf.admin — Administration Plugin

Overview

The apaf.admin plugin provides the user, group, and role management layer of APAF. It exposes REST APIs for managing the three security entities, handles session lifecycle (ping, check), and provides access to per-user profile and preferences.

Security Model

APAF uses a three-tier RBAC model:
  • User — an individual account with login, password, and optional API key
  • Group — a named collection of Users that carries security roles
  • Role — a named permission checked by REST handlers (e.g. administrator, developer)
A user inherits all roles from every group they belong to.

REST API — Session

MethodPathRoleDescription
GET/apaf-admin/session(none)Check whether a user session is active
PUT/apaf-admin/session(none)Ping the current session to keep it alive

REST API — Users

MethodPathRoleDescription
POST/apaf-admin/user/querymanageUserQuery the list of registered APAF users
POST/apaf-admin/usermanageUserRegister a new User
PUT/apaf-admin/usermanageUserUpdate an APAF User record
DELETE/apaf-admin/user/:idadministratorDelete an APAF User record
GET/apaf-admin/user/:idmanageUserGet an APAF User by UUID

REST API — Profile & Preferences

MethodPathRoleDescription
GET/apaf-admin/profile(authenticated)Get the connected user's profile record
PUT/apaf-admin/profile(authenticated)Update the connected user's profile record
GET/apaf-admin/preferences(authenticated)Get the connected user's preference records
GET/apaf-admin/profilePageContributions(none)List registered profile page extensions

Extension Points

  • apaf.admin.user.preference — declare a per-user preference namespace (consumed by plugins such as apaf.workflow for editor settings)
  • apaf.admin.profile.provider — contribute additional tabs to the user profile page

MCP Tools

The plugin registers four MCP tools via the npa.mcp.tool extension point: queryUsers, queryGroups, findGroupById, queryRoles.
