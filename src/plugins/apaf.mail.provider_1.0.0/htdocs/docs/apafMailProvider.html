apaf.mail.provider — Mail Provider Plugin

Overview

The apaf.mail.provider plugin configures the SMTP mail transport for APAF and exposes a REST endpoint that servlets, workflows, and snippets can use to send emails without embedding SMTP credentials in application code.

REST API

MethodPathRoleDescription
POST/apaf-mail/sendcoreServicesSend an email message

Request Payload

{
  "from": "sender@example.com",  // sender address (required)
  "to": "recipient@example.com",  // recipient address (required)
  "subject": "Hello",              // email subject (required)
  "content": "<p>Body text</p>",   // email body (required)
  "asText": false                // true = plain text, false = HTML (optional)
}

SMTP Configuration

The SMTP provider is configured via environment variables:
VariableDescription
SMTP_HOSTSMTP server hostname
SMTP_PORTSMTP server port (default: 587)
SMTP_USERSMTP authentication username
SMTP_PASSWORDSMTP authentication password
SMTP_SECUREtrue to use TLS (default: false)

Usage from a Servlet

 1. let res = context.httpResponse;
 2. let npaRest = context.runtime.getPlugin('npa.rest');
 3. npaRest.post('/apaf-mail/send', {
 4.   from: 'noreply@myapp.com',
 5.   to: context.user.email,
 6.   subject: 'Your report is ready',
 7.   content: '<b>Download your report</b>'
 8. }, function(err, result) {
 9.   res.json({ sent: !err });
10. });

Notes

  • The underlying transport is provided by npa.mail (Node.js nodemailer).
  • If no SMTP credentials are configured, the endpoint returns an error at runtime.
  • The apaf.workflow plugin includes a built-in Send Mail workflow node that internally calls this endpoint.
