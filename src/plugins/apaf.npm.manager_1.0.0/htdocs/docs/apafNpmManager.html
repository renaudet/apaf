apaf.npm.manager — NPM Package Manager

Overview

The apaf.npm.manager plugin provides an administration interface and REST API for managing server-side Node.js npm package dependencies in APAF.

It works in conjunction with apaf.updater to ensure that all explicit npm dependencies required by active plugins (declared via npmDependencies in their manifest.json) as well as user-declared dependencies (for custom fragments, servlets, and workflows) are automatically reconciled in the runtime's package.json and installed via npm install.

All operations require the administrator security role.

Features

  • Consolidated Inventory: Real-time overview of all installed and declared npm packages, classified by origin (Runtime base, Plugin dependency, User declared).
  • Consumer Tracking: View which plugins require each specific npm package.
  • User Package Declaration: Allows administrators and developers to add npm packages directly from the web browser for use in custom fragments and workflows.
  • Automatic Reconciliation: Rebuilds package.json and runs npm install --no-audit --no-fund safely in the background.

REST Handlers

Method Route Security Role Description
GET /apaf-npm/packages administrator Returns the full inventory of npm dependencies, target versions, and consumer plugins.
POST /apaf-npm/install administrator Adds a user-declared npm package and triggers reconciliation + npm install. Payload: {"name": "lodash", "version": "^4.17.21"}
POST /apaf-npm/uninstall administrator Removes a user-declared npm package and reconciles dependencies. Payload: {"name": "lodash"}
POST /apaf-npm/reconcile administrator Forces a full reconciliation of package.json against active plugins and runs npm install.
