APL Developer Guide

Overview

APL (APAF Programming Language) is a JavaScript-like scripting language embedded in APAF. It is primarily used to write micro-service scripts that are stored in the database and executed on demand for each incoming HTTP request. APL scripts are compiled and run server-side by the apaf.apl plugin.

Language syntax

APL is intentionally similar to a subset of JavaScript. Developers familiar with JS will feel at home. The following sections describe all supported language constructs.

Variables

Variables are declared with var (mutable) or const (immutable). A var declaration without an initializer creates an undefined variable.
var x;
var name = "Alice";
var count = 0;
const PI = 3.14159;
var items = [10]; // array of 10 elements

Arithmetic and string operators

var sum = a + b;
var diff = a - b;
var prod = a * b;
var quot = a / b;
var msg = "Hello, " + name + "!"; // string concatenation

Comparison and logical operators

a == b   a != b
a < b   a > b   a <= b   a >= b
a || b // logical OR
a && b // logical AND
!condition // unary NOT

Assignment and post-increment / post-decrement

x = 10;
x++; // equivalent to x = x + 1
x--; // equivalent to x = x - 1

Arrays

Arrays are declared with a fixed size. Individual elements are accessed and assigned by index. The special .length property returns the array size.
var a = [5]; // declare array of 5 elements
a[0] = "first";
a[1] = 42;
var len = a.length;
var first = a[0];

Object property access

Objects are typically received from built-in functions or from the initial execution context. Properties can be read and written using dot notation.
var method = request.method;
var body = request.body;
response.status = 200;
response.data = body.name;

Conditional — if / else

if (x > 0) {
  var sign = "positive";
} else {
  var sign = "negative or zero";
}

// if without else is also valid
if (name == "admin") {
  print("Welcome, admin!");
}

For loop

The loop variable must be declared before the for statement, and the step expression is an assignment (not a post-increment).
var i = 0;
for (i = 0; i < 10; i + 1) {
  a[i] = i * 2;
}
Note: the third part of the loop header is a pure expression — the result of i + 1 is assigned back to i after each iteration.

While loop

var n = 1;
while (n < 100) {
  n = n * 2;
}

Functions

Functions are declared with the function keyword. They support parameters, local variables, and a single return statement at the end.
function add(a, b) {
  return a + b;
}

var result = add(3, 7);
Functions are first-class citizens in the script scope: a function declared anywhere in the program is callable from any subsequent line (including from within other functions).

Function calls as statements

A function call can be used as a standalone statement (its return value is discarded):
print("Processing request...");
log(request.method, request.params.id);

Micro-service script pattern

The standard pattern for an APAF micro-service script is to define a function named process(request, response). The caller (typically apaf.micro.services) appends the call process(request, response); to the stored source before execution, passing a pre-populated request object and an empty response object as context variables. The script fills in response, which the caller reads back after execution.
// Minimal micro-service script
function process(request, response) {
  var id = request.params.id;
  response.status = 200;
  response.message = "ok";
  response.data = "Processed: " + id;
}
The request object fields:
FieldDescription
request.methodHTTP method: "GET", "POST", "PUT", "DELETE"
request.paramsURL path parameters (e.g. request.params.id)
request.queryURL query-string parameters
request.bodyParsed JSON request body (for POST / PUT)
request.headersHTTP request headers
The caller reads result.memorySpace['.response'] after execution, so the script only needs to populate the response variable it received as a parameter.

Built-in functions

Built-in functions are provided by the caller at execution time. The set of available built-ins depends on the calling context. In the micro-services context, the following built-in is always available:
FunctionArgumentsDescription
print(msg)stringWrites a message to the APAF server log at info level, prefixed with the micro-service name.
When invoking APL from a custom plugin, any JavaScript function can be exposed as a built-in. Refer to the apaf.apl Plugin Reference for the declaration syntax.

Scoping rules

  • Variables declared with var outside any function are global to the script and live in the root namespace for the duration of execution.
  • Variables modified inside a for or while loop body are visible after the loop ends (no loop-level scoping).
  • Function calls create a new scope: parameters and variables declared inside a function are local to that function call and do not interfere with the outer scope.
  • Context variables injected by the caller (e.g. request, response) are available as globals throughout the script.
