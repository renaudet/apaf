apaf.workspace — Workspace Plugin

Overview

The apaf.workspace plugin manages the APAF server-side workspace — a managed file storage area internal to the running APAF instance. The workspace is entirely distinct from the local developer filesystem and from the VS Code workspace. Files are organized into projects (top-level folders) and sub-folders. All file paths are transmitted as Base64-encoded strings to safely carry path separators in URL segments.

REST API — Projects & Folders

MethodPathRoleDescription
POST/apaf-workspace/projectdeveloperCreate a new project in the workspace
POST/apaf-workspace/project/findoperatorList projects (filter by name or type)
POST/apaf-workspace/folderdeveloperCreate a sub-folder within a project
GET/apaf-workspace/folderoperatorList folder contents (query params: project, folder, hidden)

REST API — Files

MethodPathRoleDescription
GET/apaf-workspace/file/:encryptedoperatorRead a text file (path is Base64-encoded)
GET/apaf-workspace/binaryFile/:encryptedoperatorDownload a binary file (path is Base64-encoded)
PUT/apaf-workspace/file/:encrypteddeveloperCreate or overwrite a text file
POST/apaf-workspace/file/:encrypteddeveloperUpload a binary file as multipart/form-data
DELETE/apaf-workspace/:encrypteddeveloperDelete a project, folder, or file

Path Encoding

All file and folder paths are relative to the workspace root and must be Base64-encoded before being passed in URL segments:
// Example: encode the path "myProject/src/app.js"
let encoded = btoa('myProject/src/app.js');
// Use encoded in the URL: /apaf-workspace/file/bXlQcm9qZWN0L3NyYy9hcHAuanM=

MCP Tools

The plugin registers eight MCP tools covering the full workspace lifecycle: findWorkspaceProjects, createWorkspaceProject, createWorkspaceFolder, readWorkspaceFolderContent, readWorkspaceFile, readWorkspaceBinaryFile, writeWorkspaceFile, and a delete tool.

Notes

  • The workspace root directory is configured via the npa.workspace NPA plugin and defaults to a sub-directory of the server process working directory.
  • Binary file upload uses multipart/form-data; text file creation uses a plain JSON body with a content string field.
  • The Workspace Explorer UI (plugin apaf.workspace.explorer) provides a graphical interface over these REST APIs.
