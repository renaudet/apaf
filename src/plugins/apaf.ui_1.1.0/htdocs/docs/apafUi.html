apaf.ui — Advanced UI Plugin

Overview

The apaf.ui plugin contributes APAF-specific UI components to the NPA UI framework (npa.ui.tools.core). Components live in the apafUi namespace and are referenced in a component JSON configuration as apafUi.<Name>.

Since version 1.1.0 the plugin also serves the Chart.js library (v4.4.7, UMD build) from /apaf-ui/lib/chart.umd.js, and provides the LineChart component.

Components

ComponentTypeDescription
SourceCodeEditorapafUi.SourceCodeEditorButton opening a modal source code editor with a snippet library
LineChartapafUi.LineChartLine chart based on Chart.js; the canvas is managed by the component

LineChart component

The developer only declares a placeholder <div> and a JSON configuration. The component creates and sizes the <canvas>, loads Chart.js on demand (only if the Chart global is not already defined), builds, updates and destroys the chart instance. The chart is responsive and fits the width of its parent <div>.

Usage

<div id="salesChartDiv" class="npaUi" data-config="/my-plugin/json/salesChart.json"></div>
{
  "id": "salesChart",
  "type": "apafUi.LineChart",
  "version": "1.0.0",
  "configuration": {
    "title": "@my.plugin.sales.title",
    "height": 300,
    "labelField": "month",
    "series": [
      {"field": "revenue","label": "@my.plugin.sales.revenue"},
      {"field": "cost","label": "@my.plugin.sales.cost","color": "#e5484d","fill": true}
    ],
    "yAxisLabel": "EUR",
    "datasource": {
      "type": "local",
      "uri": "/my-plugin-api/sales",
      "adapter": "@.data"
    }
  }
}

Configuration

PropertyTypeDescription
titlestringOptional chart title; supports i18n references (@key)
heightintegerChart height in pixels (default 300)
labelFieldstringRow attribute used for the X axis labels
seriesarrayOne entry per curve: field (row attribute holding the Y value), optional label, color and fill
xAxisLabel / yAxisLabelstringOptional axis titles; support i18n references
legendbooleanDisplay the legend (default true)
smoothbooleanSmooth the curves (default true)
beginAtZerobooleanForce the Y axis to start at 0 (default false)
datasourceobjectData source, same conventions as the Datatable component (see below)
selectionListener / selectionProviderboolean / stringWhen set, the chart is refilled when the given component fires a select event
selectionAdapterstringExpression returning the rows array from the selected item (@ represents the item); the item itself is used if omitted

Datasource

TypeDescription
local (default)REST call on uri (method, payload optional). The rows are read from the data attribute of the response, or from the result of the adapter expression (@ represents the response)
managedRows returned by query(payload) of the DataManager component identified by manager
manual (or no datasource)Rows provided by the application through setData(rows)

Methods

MethodDescription
setData(rows)Replace the displayed rows and update the chart
refresh()Reload the data from the datasource
onItemSelected(item)Selection listener callback

Events

Clicking a point fires the select event with {"source": <component id>, "item": <the row>}, so other components can listen to it with selectionProvider.

Chart.js library

The library is served as a static resource of this plugin. Any other page can use it directly:

<script src="/apaf-ui/lib/chart.umd.js"></script>
