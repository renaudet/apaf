apaf.dev — Development Plugin

Overview

The apaf.dev plugin is the runtime development workbench of APAF. It manages fragments — reusable JavaScript code units — and applications — published single-page UIs. Both are stored in CouchDB and do not require a server restart to deploy.

Fragment Types

TypeDescription
snippetA reusable server-side code block (no HTTP endpoint)
libraryA JavaScript library loaded by APAF applications in the browser
servletA JavaScript fragment exposed as a dynamic HTTP endpoint via apaf.dyn.api
workflowNodeA custom node type usable in the Workflow editor
mcpToolA dynamic MCP tool exposed to AI agents without server restart

Events

After every fragment mutation, apaf.dev emits an internal event via the npa.event.broker service:
event name: 'apaf.fragment.changed'
event data: { action: 'created' | 'updated' | 'deleted', fragment: <record> }
This allows other plugins (such as apaf.generic.mcp.tools) to invalidate their caches reactively without polling.

Extension Points

  • apaf.dev.snippet.provider — contribute code snippet templates shown in the fragment editor toolbar
  • apaf.dev.editor.wizard.provider — contribute guided wizard dialogs for the fragment editor
  • apaf.dev.editor.documentation.provider — contribute documentation pages linked from the fragment editor

MCP Tools

The plugin registers MCP tools for fragment and application management: queryFragments, findFragment, createFragment, updateFragment, queryApplications, findApplication, createApplication, updateApplication.
