apaf.workspace.explorer — Workspace Explorer

Overview

The apaf.workspace.explorer plugin provides the My Workspace page, a browser-based explorer for the APAF server-side workspace. The workspace itself (projects, folders and files stored on the server hosting APAF) is managed by the apaf.workspace plugin; the explorer is a pure UI client of the /apaf-workspace REST APIs.

The page is available from the built-in applications menu (My Workspace) and requires the coreServices security role. Its URL is /apaf-workspace-explorer/html/workspaceExplorer.html.

Page Layout

The page is split into two resizable panes:

  • Left pane — a toolbar and a tree showing the projects visible to the current user, with their folders and files. Folder contents are loaded lazily, the first time a project or a folder is selected.
  • Right pane — the content of the selected file (text editor, image viewer or download panel, see Content Display). When no file is selected, a hint is displayed.

Files can also be uploaded by drag & drop: select a project or folder, then drop a file on the tree area. Only the first dropped file is uploaded.

Personal and Shared Projects

The project type is chosen at creation time and is stored in the project .project descriptor:

  • Personal projects (type general) are owned by their creator (createdBy = user login). They are visible and modifiable only by their owner and by administrators. They are displayed with the icon.
  • Shared projects (type shared) are owned by the system account, whoever created them. They are visible and modifiable by all users. They are displayed with the icon.

When the apaf.ext.workspace.sharing extension is installed, shared projects are also the only projects replicated between linked APAF instances.

Content Display

When a file is selected, the right pane adapts to its extension:

KindExtensionsDisplay
Text txt log json js html htm css csv java py sh bat cmd jtp xml md yaml yml project The whole file is loaded into a read-only text editor. Click Edit to modify it, then Save to write it back to the server
Image png jpg jpeg gif bmp tiff tif Image viewer showing the file name, size and dimensions (in pixels). The image is scaled down to fit the pane, keeping its aspect ratio, and is never enlarged beyond its natural size
Other any other extension (pdf zip docx xlsx pptx db, …) File name and size, with a Download button. The content is not displayed

Sizes are displayed in bytes (o), kilobytes (Ko) or megabytes (Mo).

Partial Content Reading

The explorer page always loads text files entirely. For large files (logs, exports…), the apaf.workspace binary file API supports partial reading through query parameters on GET /apaf-workspace/binaryFile/:encrypted (the path parameter is the Base64 encoding of <project>/<file path>):

ParameterDescription
tailReturns the last N lines of the file (read from at most the last 512 KB)
byteOffset0-based byte offset of a chunk to read
byteLengthChunk length in bytes (default 64 KB, maximum 256 KB)
encodingbase64 (default) or utf8 for the returned chunk

Without any of these parameters, the whole file is downloaded. The same options are exposed to AI agents by the readWorkspaceBinaryFile MCP tool.

Security

  • Access to the page requires the coreServices role.
  • Every operation is checked server-side by apaf.workspace: non-administrator users can only see and modify their own projects and the shared projects.

Internationalization

All labels are provided by the plugin locale files (i18n/apaf_workspace_explorer_en-US.locale and _fr-FR.locale), with keys prefixed by apaf.workspace.explorer..
